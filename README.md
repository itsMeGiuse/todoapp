# Todoapp

A **full-stack** to-do application built and hosted from scratch: a FastAPI REST
API, a PostgreSQL database and a vanilla JavaScript frontend, all running on
Debian Linux installed on an old 32-bit netbook.

A learning project built to get hands-on with every layer of the stack, from the
operating system all the way to the button in the browser.

## What it does

A to-do list with the full set of operations (CRUD):
- add a task;
- list all tasks;
- mark tasks as done;
- delete tasks.

## Stack

- **Backend:** Python, FastAPI
- **Database:** PostgreSQL (`pg8000` driver, pure Python)
- **Frontend:** HTML, CSS and JavaScript (no framework, no build step)
- **Environment:** Debian Linux, project managed with `uv`

## Technical choices

- **`pg8000` instead of `psycopg`:** the netbook is 32-bit, and prebuilt
  packages for the more common drivers were not available for that
  architecture. `pg8000` is written entirely in Python, so it runs anywhere
  without compilation.
- **Parameterized queries:** all values are passed to the database through
  placeholders, never concatenated into the SQL string, to prevent SQL
  injection.
- **Secrets kept out of the code:** the database password is read from a `.env`
  file that is excluded from version control; the repository only ships
  `.env.example`.

## Requirements

- Python (managed with `uv`)
- A running local PostgreSQL instance

## Database setup

Connect to PostgreSQL as an administrator and run:

```sql
CREATE USER todo_user WITH PASSWORD 'choose_a_password';
CREATE DATABASE todo_db OWNER todo_user;
\c todo_db
CREATE TABLE attivita (
    id SERIAL PRIMARY KEY,
    testo TEXT NOT NULL,
    fatta BOOLEAN NOT NULL DEFAULT false,
    creata_il TIMESTAMP NOT NULL DEFAULT now()
);
ALTER TABLE attivita OWNER TO todo_user;
ALTER SEQUENCE attivita_id_seq OWNER TO todo_user;
```

## Configuration

Copy the example file and set the password you chose above:

```bash
cp .env.example .env
# then open .env and set TODO_DB_PASSWORD
```

## Running

```bash
uv sync
uv run uvicorn main:app --reload
```

The app is served at `http://127.0.0.1:8000`:
- `/` the to-do page;
- `/attivita` the API in JSON format;
- `/docs` the interactive documentation generated by FastAPI.

## What I learned

- Installing and administering Linux (Debian) and PostgreSQL from the command line.
- Designing a table and writing SQL queries (CRUD).
- Building a REST API with FastAPI and understanding HTTP methods.
- Connecting a frontend to a backend with `fetch`.
- PostgreSQL permissions (object ownership) and secret management.
- Defending against SQL injection with parameterized queries.
